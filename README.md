# [Site_Ong](https://github.com/Guizinho0711/SIte_Ong)

Website desenvolvido para a gestão e divulgação de uma organização, contendo interface voltada para o usuário final e área administrativa restrita.

## Funcionalidades

* **Área do Usuário:** Página inicial (`index.html`) e páginas públicas estruturadas para apresentação institucional e navegação dos visitantes.
* **Área Administrativa:** Painel de controle (`admin.html`) para gerenciamento interno.
* **Integração com Banco de Dados:** Configuração de esquemas relacionais utilizando PLpgSQL (`schema.sql`) e scripts de conexão/manipulação de dados (`db.js`, `config.js`).

## Tecnologias Utilizadas

* **Frontend:** HTML5, CSS3 (`style.css`), JavaScript (`script.js`, `public.js`, `admin.js`)
* **Backend / Banco de Dados:** PLpgSQL

## Estrutura do Projeto

* `index.html`: Página principal acessível aos usuários.
* `admin.html`: Painel de administração.
* `script.js` / `public.js`: Lógicas e interações do lado do cliente.
* `admin.js`: Controladores e funções da área administrativa.
* `db.js` / `config.js`: Configurações de banco de dados e ambiente.
* `schema.sql`: Estrutura do banco de dados relacional.
* `style.css`: Folha de estilos global do sistema.
